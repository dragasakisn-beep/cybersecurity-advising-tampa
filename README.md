# Cybersecurity Advising · Tampa

Adviser-maintained resources for undergraduate cybersecurity students, personally maintained by **Prof. Dragassakis, KU Cybersecurity Program Advisor**.

## Pages

- `index.html`: program information, official KU resource directory, advising checklist, and planned texting service.
- `privacy.html`: Student Advising SMS privacy-policy draft.
- `terms.html`: SMS Terms & Conditions draft.
- `campaign.html`: campaign description, consent script, sample messages, and keyword plan.

The static HTML, CSS, JavaScript and SVG in this repository are the full website source. No build or dependency installation is required. GitHub Pages publishes the **main** branch from **/ (root)**.

## Privacy and service status

This is a personally maintained resource site, not a university-owned portal. No student records, SMS conversations, credentials or consent evidence belong in this public repository. The site has no student data forms or login; the checklist is not saved or submitted. Resource search runs only in the browser. GitHub may process hosting request logs under its own policies.

The SMS service is in preparation. Provider registration, support contact, data retention, AI/hosting configuration and access controls still require finalization. Policy and campaign materials are marked as drafts and must not be submitted as final policies or treated as proof that student consent was collected.

Changing these documents does not change the underlying university-advising use or establish authorization. Confirm the appropriate sender registration and institutional permissions before real messaging or student-record processing.
